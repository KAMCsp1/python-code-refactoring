# Python Code Refactoring

This project cleans up a small Python script that processes a list of numbers and a list of words. I renamed things, added docstrings and simplified the code, while keeping the output exactly the same.

## How to run

You need Python 3. From the project folder, run:

```bash
python3 undocumented_script.py
```

(On Windows, use `python` instead of `python3`.)

The output should be:

```
Processed Numbers: [3, 4, 9, 8, 15, 12, 21]
Processed Strings: apple BANANA kiwi GRAPEFRUIT CHERRY
```
